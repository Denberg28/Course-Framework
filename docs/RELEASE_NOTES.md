# Course Framework 0.4.2-rc.1 — Optimized learning-material instructions and quality review

Module generation prompts for **Gemini 3.5 Flash-Lite** and **Gemini 4 Hydrogen** now use a structured instructional-design blueprint targeting 1,100–1,600 words of direct classroom teaching content, slide-ready presentation segments with misconception/visual cues and discussion prompts, domain-appropriate worked examples, practical activities with success criteria, and balanced five-item assessments.

Per-module prompts now include course sequence boundaries (previous/next modules), learner level, outcome mapping, and adaptive lecture/lab/unassigned allocation scoping so lecture-only and informal courses no longer receive misleading laboratory instructions. Output sanitization normalizes benign bold headings/answer keys, advisory review notes report all structural and quality issues in one pass (including duplicate MCQ options, uniform answer-key letters, and unfilled placeholders), and HTML presentations preserve continuous `<ol start="N">` numbering.

This is an unsigned Windows prerelease. Extract the whole ZIP before running CourseFramework.exe. Live provider teaching quality and manual Windows acceptance remain pending.
