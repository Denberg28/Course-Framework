# Course Framework 0.3.1-rc.1 — Full syllabus workflow

Paste the original full syllabus and Generate. Streamlit restores the top-to-bottom layout: full-width input, compact controls, and course materials below. Download Markdown directly from a draft or accepted course; Save/Export stay above the preview. Optional settings, scope and outline remain collapsed, with all modules selected by default.

The supplied AE 416 Research Methods and Application syllabus is included as Example. It produces five detected modules, three outcomes and three readings, retaining 36 lecture/54 laboratory hours (90 total). Plain course headings, units, weekly hours, standing and lecture/lab tables pasted with tabs, spaces or pipes are recognized. Exact module hours reach the generation prompt, course overview and module headings; mismatched declared totals are flagged, and weeks are not inferred.

The teaching format remains discussion/presentation (introduction, numbered teaching sequence, worked example, summary), activity and five A–D MCQs with a collapsible letter key and references. Video suggestions remain excluded. Generation stays sequential and resumable; accepted material and hosted Secrets handling are retained. This release does not claim a live speed benchmark or factual validation of AI lessons. Start a fresh draft for the updated generation contract.

Automated tests use simulated providers and include the full AE 416 input. Linux/Windows verification, native startup, Windows packaging and packaged startup gate publication. This is an unsigned prerelease; live-provider teaching quality and manual Windows/browser/high-DPI/accessibility acceptance remain pending. Download and extract the entire Windows x64 ZIP before running CourseFramework.exe. Streamlit entry: main/app.py, Python 3.12.
