# Course Framework 0.3.2-rc.1 — References from the syllabus

Generation now uses the textbook and references supplied in the syllabus, regardless of subject, author, publisher or domain. The automatic agency/university/publisher catalog is removed. AE 416 prompts and module reading lists use Paler-Calmorin (1995), Adanza (1995) and Sevilla (1992), as supplied, without adding FAA/EASA/CAAP readings.

Supplied references receive stable SYL source IDs. Bibliography links from any domain are retained; model-invented URLs are flagged. Missing readings are marked without inventing replacements. Bibliographic entries are not retrieved source texts, so instructors must check module claims, citations, relevance and answer keys against the actual readings.

The full-syllabus workflow, vertical Streamlit allocation, lecture/lab hours, discussions, activities, five MCQs and collapsible keys remain. Existing accepted courses are preserved; generate a fresh draft to apply the new reference policy. Save/reopen, failure/resume, hosted Secrets and video-suggestion removal are retained.

Automated regressions use simulated providers. Linux/Windows tests, native startup, Windows packaging and packaged startup gate candidate publication. This is an unsigned prerelease; live teaching quality and manual usability/accessibility acceptance remain pending. Extract the complete Windows x64 ZIP before running CourseFramework.exe. Streamlit entry: main/app.py, Python 3.12.
