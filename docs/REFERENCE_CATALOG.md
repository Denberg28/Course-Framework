# Syllabus reference policy

New modules use the textbook and references listed in the syllabus, for any subject, author, publisher, journal or agency. The previous hard-coded FAA/CAAP/EASA/MIT/OpenStax catalog has been removed. Those sources appear only when explicitly listed in the syllabus bibliography; mentioning aviation or an agency in a topic does not add readings.

The parser recognizes Textbook(s), Reference(s), Bibliography, Reading list, Required readings, Recommended readings, and Textbooks and references headings. Entries retain their supplied bibliographic wording/order (list numbering is normalized) and receive SYL-1, SYL-2, … IDs. The model is instructed to select relevant entries and avoid outside references, invented quotations/citations/page numbers, and unsupported claims of source access. Each module includes the syllabus reading list for instructor relevance checks. Without source text, the app cannot establish which chapters support a lesson.

AE 416 uses the three entries supplied by the user: Paler-Calmorin, Laurentina, *Methods of Research and Thesis Writing* (1995); Adanza, Estela G., *Research Methods: Principles and Applications* (1995); and Sevilla, C.G., *Research Methods*, revised edition (1992). These details are reproduced from the syllabus, not independently verified bibliographic records.

HTTP(S) URLs in supplied bibliography entries can use any domain. New model-authored URLs absent from those entries are replaced with a verification marker, including formerly catalogued links. No URL or source text is automatically fetched. Raw syllabus/project data is preserved. Missing references are flagged without adding a replacement bibliography. Video-suggestion removal continues to apply to new modules.

Existing accepted material is preserved. Generate a fresh draft to apply this policy. Structural lesson/assessment validation is separate from source attribution and teaching accuracy.
