# Architecture

`course_core.py` owns extraction, outline parsing, bounded project schemas, atomic writes, and exports. `engines.py` owns HTTPS adapters and module prompts. `course_workflow.py` owns sequential module jobs, resume matching, deterministic video resources, and draft acceptance. `desktop.py` and `app.py` present the same workflow; `academy_theme.py` owns shared visual tokens.

The user flow is **paste → select agent/scope → Generate → review → Use draft → save/export**. Windows uses a single split workspace. Streamlit uses one page with no workflow tabs. File/provider options are secondary; outline review is optional. Manual keys are session-only and provider changes clear manual key/consent. `hosted_keys.py` can read a deployment-owned Gemini key from Streamlit Secrets; it is used only in the Gemini request configuration, never prefilled into widgets or copied into session/project state. A configured deployment key takes precedence over a stale manual Gemini key. Preset model IDs are editable shortcuts, not proof of account availability. There are no background model probes or paid retries.

A generation job snapshots the source, effective title, provider/model, selected indices, a configuration fingerprint, and completed module text. One request generates one module, bounded by the existing output/response limits. The adapter validates four nonempty sections: objectives, content, activities, and assessment. Before a checkpoint is exposed, the entire pending draft is checked against its character limit. This is structural validation, not teaching-quality verification.

After success, a new job dictionary is committed. A failure leaves the prior checkpoint and accepted course intact. Resume requires an exact source/title/selection match and a SHA256 configuration fingerprint (provider, model, compatible endpoint; never the key). A replacement key for the same configuration can resume. An engine/source change begins a new draft; its first failed request does not replace the older pending draft. Full completion is required for acceptance. Acceptance restores the request snapshot; existing accepted material/source changes require explicit replacement approval. Save project keeps both accepted material and the unfinished job; export omits pending work.

Windows has one worker, a bounded result queue, and a pause event. Workers never access Tk. Pause lets the current request finish and queues its result, then prevents a subsequent request. Closing can discard the active request; billing may continue. Saving while busy captures the last checkpoint delivered to Tk, not an in-flight result. Streamlit commits each successful module into session state before requesting another; a provider failure stops the loop and exposes Resume. Save/download is required for durability across application/session loss. No automatic disk or cloud persistence is claimed.

Project format 2 fields: `schema_version`, `title`, `syllabus`, `content`, `engine`, `model`, `accepted_syllabus`, `pending`. The accepted source snapshot keeps course exports consistent even while another syllabus is being edited. The pending allow-list contains only snapshot text, provider/model, a 64-character fingerprint, ascending unique selected indices, and bounded completed text. Imported format 1 migrates to 2. Unknown fields (including keys/endpoints) are discarded. The old schema cannot reopen new projects; Markdown remains portable. Writes flush a temporary sibling and atomically replace the destination.

Video resources are generated locally: two URL-encoded YouTube topic searches and explicit HTTPS YouTube/Vimeo links extracted from the supplied syllabus. Model-authored video sections are replaced, and new direct YouTube/Vimeo URLs absent from the syllabus are removed. No video search API, account, discovery/ranking, player, or availability/accuracy validation is implemented. All raw model content remains untrusted; HTML is disabled in Streamlit previews, native editing is plain text, and printable HTML escapes Markdown.

HTTPS adapters refuse redirects, keep Gemini credentials in headers, use sanitized errors, bound response sizes, and reject unfinished outputs. Streamlit compatible endpoints require public HTTPS; Windows permits localhost HTTP. This release does not alter authentication protocols or add Aero Academy content/account integration.

The generation module is named `course_workflow.py` to avoid PyInstaller’s third-party `workflow` hook. Native provider details open in a small Settings dialog so expanding them cannot push Generate off a short display.
