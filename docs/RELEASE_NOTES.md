# Course Framework 0.3.3-rc.1 — Default model and calm navigation

Gemini 3.5 Flash-Lite is now the default in Streamlit, Windows and the shared adapter. Select 3.8 Flash for demanding work, or use a custom model. Existing session selections and saved unfinished jobs keep their original model. This is a default preference, not a model speed/free-quota guarantee.

Streamlit restores the original airplane mark/favicon and adds a compact navy/gold header with a small static lesson illustration. A visible vertical scrollbar, stable page gutter, Syllabus/Course material jump links and a return link support long courses. Smooth scrolling respects reduced-motion settings. The decorative illustration hides on narrow screens; there are no animated or remote assets.

The full-width syllabus workflow, syllabus-based references, lecture/lab hours, discussions, activities, five MCQs, collapsible keys, checkpoints and hosted Secrets are retained. Start a fresh app session/reboot to see the new default; explicit model selections remain respected.

Publication requires Linux/Windows regressions, native startup, actual Chromium desktop/mobile navigation/download/overflow checks with screenshots, Windows packaging and packaged startup. Browser generation is offline and provider tests are simulated. This is an unsigned prerelease; live teaching quality and manual Windows/browser/accessibility acceptance remain pending. Extract the complete Windows x64 ZIP before running CourseFramework.exe. Streamlit: main/app.py, Python 3.12.
