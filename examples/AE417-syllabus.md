| Course Name: | AERONAUTICAL ENGINEERING PRACTIVE (OJT) LECTURE | | |
| Course Description: | The course consists of a preparatory classroom component and a supervised industry immersion program. The classroom component provides students with knowledge of aviation workplace practices, safety management systems, quality assurance procedures, maintenance documentation, engineering ethics, research application, and internship requirements. The industry immersion component provides practical exposure to actual aviation operations, maintenance, manufacturing, engineering support, and airworthiness activities in approved aviation organizations. | | |
| Number of Units for Lecture and Laboratory: | 3 units lecture, 0 unit laboratory = 3 Units | | |
| Number of Contact Hours per week: | 3 hours lecture, 0 hours laboratory = 3 Hours | | |
| Pre-requisite: | Fourth Year Standing | | |
| Course Objectives: | After completing this course, the student must be able to: | | |
| | 1. Demonstrate readiness for professional aviation industry practice. | | |
| | 2. Apply aviation safety, quality, and regulatory requirements in the workplace. | | |
| | 3. Perform assigned engineering and technical functions under supervision. | | |
| | 4. Integrate engineering knowledge with actual aviation operations. | | |
| | 5. Prepare technical reports and professional documentation. | | |
| | 6. Demonstrate professional ethics, communication skills, and teamwork. | | |
| | 7. Evaluate workplace processes using engineering principles. | | |
